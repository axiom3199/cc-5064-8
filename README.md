# 保守光栅化表面体素化器

把三角形投影到选定轴平面，保守计算被覆盖像素并映射到相交体素，生成可检查的
**表面占用**（surface occupancy）结果。体素表同时供轮廓预览与空腔连通测量使用。

> **输出含义**：本工具输出的是表面占用——只表示三角形表面穿过哪些体素，
> **不代表已获得内部实心体积**；本工具**不做内部填充**。

## 图形入口（体素覆盖）

```bash
python3 server.py [--port 8000]
# 浏览器打开 http://127.0.0.1:8000/
```

界面包含：

- **光栅调试视窗**：投影平面上的保守覆盖像素（必交/可能交）、像素中心命中点、
  三角形投影轮廓；在视窗内**拖拽可平移几何**并自动重新生成体素。
- **体素视图**：等轴投影下的保守覆盖与空间格外框，层切片滑杆逐层检查。
- **结果区**：must/may/may_only 计数、漏标/多标对照、源面列表（点击高亮其
  体素）、实际占用体素列表（点击看源面）、空腔连通测量面板（细分预算、结论、
  未决区域、细网格复验）、体素数据下载。
- 保守覆盖与空间格均由服务器**实际运算**；异常（未知场景、非法分辨率等）
  由体素覆盖界面顶部的错误横幅提示。

## 命令行（仅辅助体素覆盖）

```bash
python3 cli.py voxelize --scene duct_strip --out voxels.json   # 生成体素数据
python3 cli.py connectivity --scene duct_paper --budget 2      # 连通测量+细网格复验
python3 cli.py verify --scene tetra --scale 0.1                # 漏标/多标对照
python3 cli.py --help
```

命令行只是辅助入口；交互检查请用上面的图形界面。

## 核心规则（全库统一）

- **体素边界归属**：体素为闭集 `[o+i·h, o+(i+1)·h]`；位于共享边界面/边/角上
  的几何同时归属相邻两侧体素。区间到层号的映射只有一份实现
  （`Grid.cell_range_closed`），体素化、参考校验、连通测量、界面共用。
- **投影轴**：取三角形法向量绝对值最大的分量（投影面积最大）。
- **深度区间**：对每个被覆盖像素，用 `三角形∩像素` 的凸多边形顶点求投影轴
  方向的深度范围（深度在三角形上是线性的，顶点处取极值），再按闭集归属
  规则映射到体素层。
- **保守覆盖 ≠ 像素中心命中**：只要三角形与像素方块（闭集）相交即覆盖，
  不含任何中心点的细小三角形也不会遗漏；候选像素严格限制在投影包围盒内，
  额外覆盖有界，不会把整个包围盒标成实体。
- **退化投影回退**：法向量近零（共线/重合）的三角形无法选轴，回退为在
  包围盒内逐格做解析相交测试。
- **must / may**：候选体素经三角形-盒相交解析测试（Akenine-Möller SAT，
  闭集）确认的为**必交 must**；保守覆盖的全部候选为**可能交 may**；
  `may - must` 即保守伪占用（如薄三角贴着格界 eps 内时的外扩格），
  分开记录并可用 `verify` 对照独立参考检查漏标（必须为空）与多标。

## 空腔连通测量

预览可以保守占格（may），但连通测量遇到会决定孔道通断的格子时：

1. **精测**——每个候选体素都已做三角形-盒相交解析测试（must/may 分类）；
2. **细分**——预算允许时空间格边长减半重新体素化，收缩保守带宽；
3. **未决**——预算耗尽仍无法判定时返回 `undecided` 并给出未决区域。

结论语义：

- `connected`：找到完全由"确定自由"（不在保守覆盖中）体素组成的 6-连通
  通路，与分辨率无关，物理可信；
- `blocked`：细分到预算上限后精确占用仍隔断（**预算限定结论**，分辨率高
  化可能翻案，因此每个结果都附 `fine_mesh_verdict` 细网格复验对照）；
- `undecided`：预算耗尽，决定通断的格子未全部判定。

演示场景：细斜片贴对角线放置、下缘在格角擦过（`duct_strip`），另一张纸
封死同一条孔道（`duct_paper`）——二者在粗层得到相同的一圈候选格
（144 格，含缝隙对角带）；预算 0 时二者都未决且未决区域相同；细分后
细斜片判定连通（第 2 层露出通道）、封孔纸判定隔断，细网格复验一致。

## 场景

| key | 说明 |
|---|---|
| `duct_strip` | 细斜片（格角擦过），不封死孔道 |
| `duct_paper` | 封孔纸，精确封死对角缝隙 |
| `duct_open` | 空孔道对照组 |
| `tiny_corner` | 贴格角细三角（不含任何像素中心也不遗漏） |
| `eps_graze` | 贴格界薄片（演示保守伪占用 may_only） |
| `grid_point_tri` | 穿过格点的三角形（边界归属规则） |
| `tetra` / `cube` | 可缩放模型（`--scale 0.1/1/10` 核对漏标/多标） |

## 结构

```
voxelizer/
  geometry.py      向量、三角形-盒相交（SAT 闭集）、点-三角形距离
  grid.py          统一空间格与体素边界归属规则
  conservative.py  保守光栅化：投影、像素覆盖、深度区间
  voxelizer.py     表面体素化器：must/may 分类、源面表、参考对照
  connectivity.py  空腔连通测量：洪泛、细分预算、未决、细网格复验
  scenes.py        演示/测试场景
cli.py             命令行（仅辅助）
server.py          图形入口（HTTP + 静态页）
web/               界面（光栅调试视窗 + 体素视图 + 结果区）
tests/             unittest 与客户端冒烟
```
